A clean, modern and fully customizable landing page for your Minecraft server. Ready in minutes, no coding required.

Give your server the professional website it deserves. This template presents everything new players need to know: your server IP, live status, player count, your team, voting links and your Discord community, all in one polished, responsive page.

Every text, link, image, icon and color is changed through simple configuration files. You never have to touch the code.

---

## Features

### Hero section
- Your logo and slogan on a full-width background image
- One-click **copy server IP** button with a confirmation message
- Buttons for **Discord** and your **shop**

### Live server information
- **Live status:** Online, Offline or Maintenance
- **Online player count**, updated automatically
- Supported Minecraft versions, game mode or anything else you want to show
- Add, remove and reorder info cards freely. The cards resize automatically to fill the row.
- Choose an icon for every card from a library of over 1,500 icons
- Works with **Java and Bedrock** servers

### About section
- Image cards with a title and description
- Show as many cards as you like

### Staff carousel
- Automatically scrolling carousel with **player heads**, **usernames** and **ranks**
- Just enter the player's UUID. Usernames and heads are loaded automatically.
- Create your own ranks with **custom colors** (Owner, Admin, Builder, ...)
- The order in your config is the order on the page

### Vote section
- Link to as many voting sites as you want
- Clean, clickable cards

### Discord banner and footer
- Eye-catching call-to-action to join your Discord
- Professional footer with copyright, disclaimer, Discord and shop buttons

## Fully customizable without coding

| What | How |
| --- | --- |
| All texts, buttons and labels | Edit `site.json` |
| Server name, IP and status settings | Edit `site.json` |
| Page language | Set the language code and translate the texts in `site.json` |
| Colors and light/dark look | Choose or create a theme file |
| Logo, favicon and images | Replace the files in the `public/images` folder |
| Staff, ranks, vote links, info cards, About cards | Add or remove entries in `site.json` |
| Maintenance mode | Set one value to `true` |

## Requirements

- [Node.js](https://nodejs.org) 20.19 or newer (free) to build the website
- Any hosting that can serve static files. **No PHP, no database and no backend required.**

You can host the website for free on platforms like Vercel, Netlify or Cloudflare Pages, or on your own Linux VPS, with Docker or on any classic web hosting package. The documentation includes step-by-step guides.

## Setup in 3 steps

1. **Install:** run `npm install`
2. **Customize:** edit `site.json`, pick a theme and add your images
3. **Publish:** run `npm run build` and upload the result, or connect the project to Vercel

## FAQ

**Do I need programming skills?**
No. Everything is configured by editing simple text files. The documentation explains each step for beginners.

**Does it work with Java and Bedrock servers?**
Yes. The status display supports both. Bedrock servers only need one different setting.

**Can I change the language of the website?**
Yes. All texts are stored in the config file, so you can write them in any language and set the matching language code.

**Can I remove sections I don't need?**
Yes. Sections can be removed or reordered with a single line change, and all lists (cards, staff, votes) can be shortened or extended.

**Where does the server status come from?**
From the free public API of mcsrvstat.us. Player heads come from MCHeads and usernames from PlayerDB.

**Can I use my own colors?**
Yes. Copy one of the included theme files and change the colors.

**Does it need a plugin on my Minecraft server?**
No. The website runs completely independently and only needs your server address.
